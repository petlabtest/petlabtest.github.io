# Noto Sans SC

This directory contains Noto Sans SC 2.004 Regular and Bold for local website
delivery. The WOFF2 files have the same 30,890 Unicode mappings as the source
TTF files used for conversion. The two WOFF2 files total 8.49 MB, compared
with 21.11 MB for the source TTF files. They are distributed under the SIL
Open Font License 1.1 in `OFL.txt`.

The shared typography contract maps weights 100–500 to the Regular face and
600–900 to the Bold face. This covers the website's current 300, 400, 500, 600
and 700 declarations without browser-synthesized bold text.
