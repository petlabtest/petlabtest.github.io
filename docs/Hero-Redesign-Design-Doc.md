# 数字 PET 实验室首页 Hero 海报改版设计书

> 版本：v1.0 ｜ 日期：2026-09 ｜ 范围：`index.html` / `index-cn.html` 首页四栏轮播 Hero

---

## 一、项目背景与目标

首页 Hero（轮播海报区）是访客进入实验室网站的第一视觉入口。改版前，四栏海报为"团队合作 / 协同聚力"等主题，存在三个问题：

1. **内容散乱**：四栏之间没有叙事主线，并列堆砌，访客无法在几秒内理解"实验室在做什么"；
2. **视觉陈旧**：部分配图来自旧视频截图（仅 1440×723），拉伸模糊，风格不统一，缺乏科技深度感；
3. **标题平庸**：super-title 用"探索 / 科普 / 科学研究 / 追光者"，是标签罗列，没有叙事张力。

改版目标：**用四栏海报讲一条完整的故事线**，让访客从"光的物理本质"一路读到"人的传承"，在一屏之内完成对实验室的认知。

---

## 二、设计理念：一条"光 — 电 — 器 — 人"的史诗叙事

四栏不再是四篇独立文章的入口，而是一条**起承转合**的叙事链：

```
光（物理起源）→ 电（认知演进）→ 器（技术革命）→ 人（精神传承）
```

| 环节 | 中文 super-title | English super-title | 叙事角色 |
|---|---|---|---|
| 起 | **起源** | **The Genesis** | 从最不可见的光讲起，确立起点 |
| 承 | **演进** | **The Evolution** | 光与电如何被一步步认识（量变） |
| 转 | **变革** | **The Revolution** | 认知积累为临界，探测范式被重构（质变） |
| 合 | **传承** | **The Torchbearers** | 技术归于人，由一代代追光者接力 |

- **起承转合**：慢起 → 铺展 → 骤转 → 回响；
- **承 → 转**是关键衔接：演进（量变）→ 变革（质变），构成最有力的一对；
- **英文命名**四词统一为 "The + 单个宏大名词"，节奏工整：The Genesis → The Evolution → The Revolution → The Torchbearers。

## 三、四栏 Hero 结构详解

### 3.1 起 · 起源 / The Genesis ——《湮没之光》
- **文章**：`News-Annihilation-{cn,en}.html`
- **主题**：反物质预言 → 511 keV 湮没辐射 → 闪烁探测。从狄拉克 1928 到安德森 1932 到全数字 PET，讲"最不可见的光"如何被看见。
- **配图**：深空金色十字星芒（一对反向光线，呼应湮没光子对），1920×1080。

### 3.2 承 · 演进 / The Evolution ——《光与电的传说》
- **文章**：`News-Tale-{cn,en}.html`
- **主题**：光如何被认识、电如何被揭示、光电效应如何连接二者。
- **配图**：**光电效应的完整链条**——左侧金色不可见光子束 → 中央闪烁晶体（把不可见光转为可见光）→ 晶体右侧紧贴一块金属板（可见光经光电效应）→ 右侧蓝色电子流飞溅。由于不可见光难以直接展示，用晶体旁紧贴金属板的构图把"闪烁转换 + 光电效应"两个环节一次呈现。

### 3.3 转 · 变革 / The Revolution ——《全数字PET，再次发明PET》
- **文章**：全数字 PET 设备介绍
- **主题**：模拟到数字的整套探测范式重构。
- **配图**：**抽象几何探测器环**——冷蓝发光方块圆环 + 暗色剪影辐射结构 + 中心深邃暗孔。放弃写实照片，整张图统一为抽象科技插画，避免"写实外圈 + 抽象中心"的拼接违和感。

### 3.4 合 · 传承 / The Torchbearers ——《少年，你相信光吗？》
- **文章**：`News-Believe-Light-{cn,en}.html`
- **主题**：吸引新学生，融入使命愿景与本科实践项目（UPOP）。
- **配图**：少年剪影仰望，地面立着方块阵列金色发光环，环被斜射光束完整笼罩，金色粒子流从环中升起汇入光束。

## 四、视觉系统规范

| 维度 | 规范 |
|---|---|
| **画幅** | 1920×1080（16:9 原生，禁止拉伸旧小图） |
| **基调** | 深蓝黑深空底，低饱和、高对比、庄重深邃 |
| **配色** | 冷蓝为主色（科技/理性），暖金为高光（希望/光） |
| **意象** | 星点、光束、发光几何环、粒子流 |
| **禁忌** | 写实照片与抽象插画拼接；过曝泛白中心；光滑单线圆环（不像探测器） |
| **日期栏** | 中文"专题报道" / 英文"Feature Article" |
| **术语** | 用"湮没"（非"湮灭"） |
| **文风** | 第三人称客观叙述，禁"本文/我们"；中文正文禁"——"破折号 |

## 五、关键设计决策与迭代记录

| # | 决策 | 为什么 |
|---|---|---|
| 1 | 主题从《光与电的传说》演进为《湮没之光》 | 实验室真正研究的是 511 keV 湮没光子，原标题格局不够 |
| 2 | 四栏顺序定为 光 → 电 → 器 → 人 | 旧"团队合作/协同聚力"与叙事主线无关；新顺序形成从物理到人传承的完整链 |
| 3 | super-title 从"探索/科普/研究/追光者"改为史诗链 | 原词是标签罗列、无进程感；新词有起承转合 |
| 4 | 英文首词从 The Dawn of Light 改为 The Genesis | Evolution / Revolution / Torchbearers 都是宏大抽象名词，Genesis 与之对仗最工整 |
| 5 | 第一个 hero 从开场视频改为静态图 | 视频载入慢、REPLAY 按钮与 learn more 交互冲突；静态深空图更稳重 |
| 6 | 全数字 PET 配图放弃真实照片、改为抽象几何环 | 写实外圈 + 抽象中心拼接违和；统一抽象风后视觉自洽 |
| 7 | 光与电配图重做，呈现"不可见光→闪烁晶体→金属板→电子"完整链条 | 旧图只是两束光机械交汇，看不出光电效应；且严格区分闪烁晶体（光→可见光）与金属板（可见光→电子）两个物理环节 |
| 8 | 少年配图中心物体从"金色方框"改为方块阵列发光环 | 方框像显示器，不像 PET 仪器；方块阵列才有探测器环识别度 |
| 9 | 环要竖立、被光束笼罩、缩到腰部高 | 平躺环看不出形状；竖立+光照=被光启迪的意象 |
