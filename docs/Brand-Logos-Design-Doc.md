# UPOP 与捐赠徽标设计书

> 版本：v1.0 ｜ 日期：2026-09 ｜ 范围：页眉两枚子品牌徽标（`UPOP_LOGO.png` / `DONATE_LOGO.png`）

---

## 一、设计定位

两枚徽标位于全站页眉 PETLab 主 Logo 右侧，作为**子品牌入口**：

- **UPOP**（本科实践项目）：吸引学生进入实验室；
- **Donate**（捐赠）：引导社会支持科研。

两枚徽标共用同一套设计语言（方形徽章、PET 科研语境、深蓝/PET 蓝/橙配色），但叙事完全独立，一眼可区分。

---

## 二、UPOP 徽标

### 2.1 设计寓意（符号层）
一枚方形徽章里同时讲清"本科生实践培养"与"PET 实验室"两层含义，且**不写任何字母**：

| 图形 | 含义 |
|---|---|
| 外圈分段结构 | PET 探测器环（科研语境） |
| 中央孔径（深蓝色） | 字母 **O** |
| 两侧导师形态内部 | 两个字母 **P** |
| 下方展开学习路径 | 字母 **U** |
| 中央橙色人物 | UPOP 本科生，整个计划的核心 |
| 橙色人物向上伸展 | 学生通过实践获得能力与成长 |

→ **U–P–O–P 通过负空间隐藏在图形里**，脱离页面环境也能辨认。

### 2.2 演进史
- **v1**：图标 + UPOP 字母串 → 改为独立方形徽标；
- **v2**：学生成长为中心，融合导师协作、学习路径、环形科研环境；
- **v3（最终）**：发现 v2 看不出 PET 和 UPOP → 符号强化，把 U-P-O-P 藏进负空间，外圈改成分段 PET 环。

### 2.3 技术规格
- 600×600 透明背景 PNG；
- 配色：深蓝（主）+ PET 蓝（辅）+ 橙（核心人物）；
- 页眉显示高度与 PETLab 主 Logo 接近，适合 64px 小尺寸辨识；
- 中英文分别链接 UPOP 对应页面。

---

## 三、Donate 徽标

### 3.1 设计寓意（符号层）
与 UPOP 成套（方形徽章 + PET 环 + 橙蓝配色），但叙事独立为"支持→突破→未来"：

| 图形 | 含义 |
|---|---|
| 双手托举 | 捐赠与社会支持是科学研究的基础 |
| 中央橙色晶体 | 科研资源、探测器核心、被激发的科学信号 |
| 分段圆环 | PET 探测器系统 |
| 向上贯穿的信号束 | 突破现有技术与认知边界 |
| 环外星芒 | 新的科学发现 |
| 延伸轨迹 | 研究成果驶向未知与未来 |

→ 核心逻辑：**支持带来突破，突破通向未来**。

### 3.2 演进史
- **v1**：双手托举 + 中央橙色晶体/心形 + 上方三道信号 + 底部 `GIVE` 字样；
- **v2（最终）**：去掉 `GIVE` 字样与文字底座——用户希望更突出"科学突破"与"未来探索"，视觉重心改为"捐赠托举的科研信号突破探测器环、向未知延伸"，比带文字版更像科研机构徽标。

### 3.3 技术规格
- 600×600 透明背景 PNG；
- 配色与 UPOP 统一（深蓝/PET 蓝/橙）；
- 位于 UPOP 右侧，中文链接 `Giving-giving-cn.html`，英文 `Giving-giving-en.html`。

## 四、两枚徽标的关系

| 维度 | UPOP | Donate |
|---|---|---|
| 入口对象 | 学生 | 捐赠者 |
| 核心叙事 | 学生成长（人是核心） | 支持→突破→未来（信号束向上） |
| 符号手法 | 负空间藏 U-P-O-P | 双手托举 + 信号束突破 |
| 共同语言 | 方形徽章 / 分段 PET 环 / 深蓝+PET 蓝+橙 | 同左 |
