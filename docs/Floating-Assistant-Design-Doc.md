# PET 浮动助手挂件设计书

> 版本：v2.0（整合迭代记录）｜ 日期：2026-09 ｜ 范围：全站右下角浮动挂件（`floating-assistant.js`）

---

## 一、设计定位

挂件是网站右下角的常驻"人形"助手形象，定位为**实验室的数字化迎宾员与导航员**：

- **不干扰阅读**：默认仅一个小形象在右下角漂浮，不遮挡正文；
- **随时可召唤**：点击弹出对话气泡，提供科学家名言与全站快捷入口；
- **品牌人格化**：把"PET"这个技术名词变成一个有表情、会打招呼的机器人，降低科研网站的距离感。

---

## 二、视觉设计

### 2.1 吉祥物形象
- **造型**：蓝色"P"字母机器人（PETLAB 的首字母 P），方头方脑，大眼睛，右手食指指向上方（引导视线），机械四肢、蓝黑配色，脚边有蓝色发光边；
- **方向**：三分之四视角朝左（朝向页面内部，而非边界），符合右下角控件的视觉习惯；
- **动态**：3.4 秒循环上下微浮（-2px），像在呼吸；打开对话气泡时叠加"打招呼"动画（左右轻摆）。

### 2.2 PET 探测器环（浏览进度的核心隐喻）
- 吉祥物站在一个 **SVG 手绘的 PET 探测器环**里（双排矩形探测模块、深色机架、前后两层、模块缝红色发光线）；
- **核心隐喻**：环随页面下翻而**上下扫描移动**——页面顶部时环悬在角色头顶，阅读越深入，环越平滑地向下扫描头部、身体、腿部，到页面底部时停在脚部。把整页内容当作"被扫描的人体"，环走到哪就代表读者读到哪：既是 PET 扫描动作的具象化，也是一个**可视化的浏览进度条**。
- **空间关系**：环分前后两层，经过角色身体时产生真实的"穿过、环绕"关系（非平面叠加）。

### 2.3 配色与尺寸
- 主色：实验室深蓝 `#00305c`（气泡/文字）+ 品牌橙 `#f45a2b`（焦点描边/装饰线）；
- 桌面：挂件区 410×400px，吉祥物 118×118px；移动端（≤700px）缩小为 310×340px、吉祥物 94×94px。

## 三、交互设计

| 状态 | 行为 |
|---|---|
| 默认 | 吉祥物在环中微浮，不显示提示 |
| 悬停/聚焦 | 上方浮出提示气泡"一起探索科学 / Explore science together"；吉祥物投影加深、微亮 |
| 按下 | 吉祥物微缩（scale .96），给物理反馈 |
| 点击 | 弹出对话气泡，吉祥物切换为"打招呼"摇摆动画 |
| 打开后 | 气泡显示当日科学家名言 + 四个快捷入口 |
| 关闭 | × 按钮 / Esc / 点击外部，焦点回到吉祥物 |
| 滚动 | 探测器环从头到脚扫描移动 |

## 四、内容设计

### 4.1 科学家名言（按星期轮换）
每天展示一位科学巨匠的名言与肖像，共 7 位，按星期轮换：

| 星期 | 科学家 |
|---|---|
| 一 | 牛顿 |

| 四 | 达尔文 |
| 五 | 特斯拉 |
| 六 | 图灵 |

名言用衬线字体（Georgia / 宋体），配科学家肖像照与生卒年，营造"与大师对话"的氛围。

### 4.2 四个快捷入口
气泡底部一行四个按钮：

- **了解研究 / Research** → 研究总览页
- **支持研究 / Donate** → 捐赠页
- **参与研究 / Engage** → 参与页
- **加入团队 / Join** → 人才页

四个入口覆盖访客从"了解→支持→参与→加入"的完整转化路径。

## 五、迭代史：从 v1 到 v5

挂件经历了五轮迭代，每一轮都由具体问题驱动：

### v1 · 初版（返回顶部 + 进度环）
- 以 PETLab 蓝色立方体 Logo 为主体，加眼睛、手臂、脚、向上指引动作；
- 点击返回顶部，外围圆环显示滚动进度；
- 接入全部 307 个页面。
- **遗留问题**：方向反了（面朝边界）、形象与底盘颜色太近、功能单一。

### v2 · 朝左 + 快捷入口
- 角色改为三分之四视角朝左（朝向页面内部）；
- 底盘改用网站按钮橙色；
- 新增环绕展开的快捷入口（科学研究/加入我们/捐赠我们），"返回顶部"收进菜单。

### v3 · 探测器环 + 逐段点亮
- 形象升级为科研数字助手（缩小夸张眼睛手脚、深蓝机械关节、青色能量线）；
- 圆形底盘替换为 **28 单元立体 PET 探测器环**（前后两层，角色站在环内）；
- 环随滚动**逐段点亮**（深蓝→橙色），模拟进度灯盘。
- **遗留问题**：环不够高级、不像真探测器；"点亮"不如"扫描"像 PET。

### v4 · 从"点亮"到"扫描"（关键转折）
- 用户提出：**不用点亮，改为从头到脚的扫描动画**——环从头顶开始，随浏览下移，最后停在脚部；
- 环改为双排矩形探测模块、深色机架、青色扫描截面，更接近真实 PET 结构；
- 前后两层产生穿过环绕关系；
- "科学研究"改为"联系我们"。
- **这是设计哲学的关键转折**：从"进度灯盘"变成"PET 扫描人体"的隐喻。

### v5 · 参考真实探测器 + 修穿模
- 参考真实 PET 探测器照片（sys8.jpg）：厚实浅色金属外壳、外圈检修槽、黑色电子组件、朝圆心排列的白色长条探测模块；
- 解决"扫描穿模"（环和身体重叠）：环扩大、内孔加宽，角色从 136px 调整到 118px，让角色真正能"通过"探测器孔径。

## 六、技术实现

| 维度 | 实现 |
|---|---|
| 注入方式 | 单个 `floating-assistant.js`（defer）自动挂载到 body，全站复用，无需逐页写 HTML；配 `install-floating-assistant.mjs` 一键注入全部页面 |
| 探测器环 | 纯 SVG 手绘（双排矩形模块 + 渐变填充 + 红色发光缝），前后两层分层 |
| 双语 | 自动判断 URL 含 `-cn.html` 或 `lang=zh`，中英文文案与链接自动切换 |
| 名言轮换 | `new Date().getDay()` 按星期取 7 条名言之一 |
| 滚动扫描 | `requestAnimationFrame` 节流监听 scroll，更新环的 Y 偏移（模拟从头顶扫到脚） |
| 无障碍 | ARIA 标签、焦点管理、Esc 关闭、`prefers-reduced-motion` 降级、打印隐藏 |
| 响应式 | 700px 断点缩小挂件、隐藏提示气泡 |
| 缓存 | 版本号 `?v=YYYYMMDD-N` 统一升级，避免旧缓存 |

## 七、设计亮点

1. **主业可视化（核心隐喻）**：探测器环从头顶扫到脚，把"整页内容=被扫描的人体、环的位置=浏览进度"这一隐喻做成了微动效——环走到哪就代表读者读到哪，既是 PET 扫描动作的具象化，也是可视化的进度指示；
2. **从"灯盘"到"扫描"的转折**：v3 的"逐段点亮"是进度灯思维，v4 改为"从头到脚扫描"才真正像 PET——这个转折是整个设计的灵魂；
3. **人格化但不打扰**：默认只有一个小形象，点击才展开，既有人情味又不挡内容；
4. **每日名言**：按星期轮换 7 位科学巨匠语录，让访客每次来都有新鲜感，同时传递科学精神；
5. **转化闭环**：四个入口对应"了解→支持→参与→加入"，是全站导航的浓缩版；
6. **真实感**：v5 直接参考真实 PET 探测器照片改环的结构，并解决"穿模"问题，让扫描动画在空间上可信；
7. **零依赖**：纯原生 JS + SVG + CSS，无第三方库，加载快、易维护。
